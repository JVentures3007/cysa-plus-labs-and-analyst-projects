# Chapter 12 — Security Reporting and Documentation

## Portfolio summary

This chapter set demonstrates how technical evidence becomes decision-ready communication: a leader-facing vulnerability report, a critique of a public incident disclosure, and a structured practice incident report from synthetic logs.

## Labs completed

| Lab ID | Activity | Demonstrated outcome |
|---|---|---|
| CYSA-C12-L01 | Leader-facing vulnerability report | Reframed previously verified vulnerability findings, remediation evidence, and residual limitations for leadership without claiming a new scan. |
| CYSA-C12-L02 | Public incident report critique | Evaluated a public disclosure for clarity, evidentiary gaps, stakeholder guidance, oversight, and future protections while treating omissions as unknowns. |
| CYSA-C12-L03 | Synthetic incident report | Converted bounded authentication-log findings into a structured incident report with scope, confidence, limitations, and response recommendations. |

## Reporting approach

1. Identify the audience and the decision the report must support.
2. Separate verified observations, sourced statements, hypotheses, and recommended next steps.
3. Preserve corrections and negative findings rather than simplifying the record.
4. Translate technical detail into operational impact, urgency, ownership, and residual risk.
5. State unavailable evidence explicitly and avoid treating silence in a source as proof that an event did not occur.

## Results and lessons

- Executive reporting should retain the evidence boundary even when it compresses technical detail.
- Prior results may be reused when provenance is clear; reuse does not imply a new scan or recurrence.
- A public incident notice can be evaluated for completeness without inventing facts the notice does not provide.
- Synthetic log findings can demonstrate reporting technique, but they cannot support claims of a real breach, live containment, or attacker attribution.
- Recommendations are more useful when they identify owners, verification steps, and conditions for closure.

## Evidence and limitations

The reviewed evidence consisted of lab-specific reports/worksheets and chapter-level completion summaries. Hypothetical teaching conditions and synthetic events are labeled as such. This public version excludes raw evidence, identifiers, screenshots, course question text, and learner answers.
