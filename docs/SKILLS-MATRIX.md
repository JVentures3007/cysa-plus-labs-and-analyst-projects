## How This Matrix Is Used

The purpose of this matrix is to show the difference between:

- material studied,
- guided labs performed,
- independently demonstrated skills,
- and integrated portfolio-level capability.

As projects mature, entries should be updated from **Building** or **Planned** to **Demonstrated**, with direct links to the relevant project documentation.
