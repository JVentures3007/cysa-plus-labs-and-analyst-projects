# CySA+ Labs & Analyst Projects

Hands-on cybersecurity labs, analyst exercises, technical documentation, and capstone work completed while studying the CompTIA CySA+ certification path.

This repository is a working portfolio of applied security analysis skills—not a certification claim. The focus is on demonstrating how concepts were practiced, documented, and connected to real analyst workflows.

## Portfolio Focus

The work in this repository covers:

- Security operations and analyst workflows
- Threat intelligence and indicator analysis
- Port scanning, fingerprinting, and service enumeration
- Vulnerability management and remediation reporting
- Incident response and incident documentation
- Log, event, and evidence analysis
- MITRE ATT&CK mapping
- Public incident report review
- Security reporting for technical and nontechnical audiences
- Automation and AI-assisted security operations concepts
- Analyst documentation, findings, and recommendations
